# Trash Dash 2.0

Selective greenfield rebuild of Trash Dash. The sibling V1 repository remains the legacy reference implementation and is not part of this repository's history.

Approved design sources live under `docs/design/trash-dash/`. Gameplay implementation is intentionally absent from this bootstrap. Godot with typed GDScript is the accepted engine foundation; a disposable native-platform spike must pass before production gameplay begins.
