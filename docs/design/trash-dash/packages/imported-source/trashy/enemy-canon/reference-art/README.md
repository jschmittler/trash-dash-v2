# Canonical Enemy Reference Art

These PNG files are the approved visual source of truth supplied during the Enemy Master Specification process.

Rules:

- Do not overwrite these files with runtime exports.
- Do not crop, recolor, clean up, regenerate, or optimize these originals in place.
- Derive new animation/source files elsewhere in the repository.
- Use `../ASSET_MANIFEST.md` SHA-256 values to detect accidental modification.
- A deliberate replacement of any canonical image is a canon revision and requires specification/changelog updates.
