# Canonical Boss Bible

Status: **STRICT PROJECT CANON**  
Scope: boss visuals, animation, VFX, attacks, story, dialogue, audio direction, promotional art, merchandise, and all generative prompts  
Visual authority: approved sheets under `../../../reference/characters/`

## Mandatory use

Before creating or changing anything involving a boss:

1. Read this file and the boss-specific file in full.
2. Inspect the approved source sheet named in that file.
3. Copy all relevant locked traits into the working brief or prompt. Never rely on the boss name alone.
4. Preserve identity, silhouette, anatomy, palette, equipment, material, posture, movement vocabulary, personality, and effects language.
5. Treat an unmentioned detail as unresolved—not permission to redesign.
6. If a requested change contradicts canon, identify the conflict and obtain an explicit canon amendment before proceeding.

## Authority and conflict order

1. Explicit later canon amendment approved by the project owner.
2. Approved visual reference sheet for directly visible facts.
3. Boss-specific canon file for normalized descriptions, intent, narrative, attacks, and prompt rules.
4. This shared bible for cross-boss rules.
5. Older design notes, conversation summaries, filenames, or generated prompts.

The visual sheet wins for observable appearance. Do not “correct” irregular teeth, asymmetry, grime, scars, proportions, or improvised construction. If a prose count is approximate because animation deformation changes visibility, preserve the visual pattern rather than forcing an anatomically neat count.

## Canon vocabulary

- **LOCKED:** immutable without explicit owner approval.
- **CONTROLLED:** may vary only within the limits stated.
- **INFERRED CANON:** narrative or functional interpretation adopted as project canon; it must be followed until explicitly revised.
- **TBD:** unresolved. Do not invent a permanent answer.

## Shared visual contract

All bosses use polished hand-painted 2D side-view action-game art: thick irregular near-black outlines; compact, exaggerated proportions; strong silhouettes; textured interior shading; and visibly dirty, dented, patched, greasy, hairy, cracked, corroded, or asymmetrical surfaces. Default presentation is a three-quarter side profile facing screen-right. Characters must remain readable at gameplay scale.

Effects use cleaner and brighter colors than bodies: toxic chartreuse, electric cyan, cosmic violet, hot yellow, red-orange, and white. Debris, droplets, dust, sparks, stars, speed streaks, and ground scars may cross the body bounds. Loose parts use delayed secondary motion. Squash-and-stretch is required for energy and impact but cannot alter identity-critical anatomy.

Never reproduce the magenta or green sheet-inspection backgrounds. Never convert the designs into clean vector mascots, smooth plastic 3D models, thin-line anime characters, realistic animals, sanitized products, or generic fantasy monsters.

## Scale policy

Sheet scale is internally relative, not a universal measurement chart. Preserve each boss's proportions and relative gameplay category. Do not assert exact feet, meters, age, or weight in outward-facing canon unless a future scale chart locks them.

## Prompt compliance footer

Attach this requirement to every boss-related generation task:

> CANON COMPLIANCE: Read the Canonical Boss Bible and the named boss file in full, then inspect the approved visual sheet. Every locked trait is mandatory. Preserve silhouette, anatomy, proportions, colors, materials, equipment, posture, expression language, animation vocabulary, effects palette, personality, and story role. Do not add identity-changing anatomy, clothing, weapons, markings, powers, or lore. Do not omit defining traits. Resolve ambiguity from the approved sheet; stop on a genuine conflict. Use a transparent background for production art unless the brief explicitly requests a canonical environment.

## Change control

A canon amendment must name the boss, quote the field being changed, state the replacement, explain whether existing art is grandfathered or superseded, and update both the boss file and any affected approval record. Casual prompt wording does not amend canon.
