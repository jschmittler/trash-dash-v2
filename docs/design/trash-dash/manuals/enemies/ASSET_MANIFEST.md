## Asset classification rules

- `CANON_CONCEPT`: approved concept art / sprite sheet that establishes visual canon.
- `CANON_SPRITE_SOURCE`: approved production source used to derive runtime sprites.
- `RUNTIME_EXPORT`: game-ready derivative used by runtime.
- `DERIVED_ANIMATION`: new animation derived from canonical anchor art.
- `VFX`: visual-effects-only asset.
- `PROP`: independent prop/equipment/projectile asset.
- `UNKNOWN / NEEDS REVIEW`: repository asset whose role/authority has not been verified.

## Repository audit instructions

After installing this package, Codex should search the project for source art, exports, animation atlases, VFX, props, enemy configs, and level placements. Add actual project paths to this manifest without changing the canonical concept path or hash.

Do not label a runtime asset canonical simply because it is currently used in the game. Verify its relationship to the approved concept art first.

## Canon art integrity

The SHA-256 values above allow future audits to detect accidental edits to the approved reference PNGs. If an approved concept image must change, treat that as a canon revision and update the specification/changelog intentionally.
